# W Supermarket

## Overview

W Supermarket is a Java Swing desktop application for supermarket management.

The application includes role-based login, inventory operations, and employee or seller records.

## Features

- Role-based login
- Inventory management
- Create, read, update, and delete operations
- Employee or seller records
- Desktop graphical user interface

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
- Database Management
